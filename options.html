Connection
Your self-hosted Memos instance URL, without a trailing slash.
In Memos, go to Settings → API Tokens and create a new token. Paste it here.
How to use
  1. Highlight any text on a webpage
  2. Right-click → Save to Memos
  3. Works on images, videos, audio, and links too

Each saved note includes a Source link back to the original page.
